# Pipeline Brief Writer

Use this to write the final brief.

Read first:

- `../linkedin-ads/references/brief-template.md`
- `../linkedin-ads/references/operator-thesis.md`
- `../linkedin-ads/references/safe-apply-model.md`

## Required Context

Load brand context first, then use the latest account/export data:

- `profile.md`
- `audience.md`
- `offer.md`
- `voice-profile.md`
- `learnings.md`
- latest brief, draft, connected cache, exports, lead files, and CRM notes

Do not invent performance. If a data source is missing, say what is missing and how that affects confidence.

## Structure

- executive summary
- buyer-quality diagnosis
- account/campaign structure
- creative and offer angle
- lead form and sales handoff
- Thought Leader Ads opportunities
- approved-safe next actions
- manual-only recommendations

## Voice

Be direct. Make the business implication obvious. Avoid dashboard narration.

Every section should answer:

- why this matters
- what to do next
